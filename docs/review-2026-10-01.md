# Review and upgrade pass — 1 Oct 2026

## What the app is for

One contract civil designer producing 11×17 fiber plan sets for Senawave, from ArcGIS Pro through
BricsCAD to a sealed PDF, needs one place that answers three questions every day: *what am I working
on*, *what did people say about it*, and *how is this step supposed to be done*. The tool is a
local-first tracker (projects → sheets → workflow → QC → permits → notes → time) with the Plan
Production Guide embedded as data, meant to be used alone first and shared with David and Jesse later
through one JSON file in Google Drive. Its spirit is "the guide and the work in the same window":
every checkbox points at a guide section, and every guide number can be used from the calculator.

## Top weak points and the fix applied

1. **Deleted rows came back after a sync.** The merge was "keep what either side has", so deleting the
   sample project on one device and syncing from another restored it. *Fix:* soft delete. Every
   delete sets `deletedAt` and bumps `updatedAt`, so it wins the newest-wins merge like any edit. The
   UI reads a filtered view (`useAppData`), the raw state keeps the tombstone, and tombstones older
   than 90 days are purged on load. Sample-data removal uses the same path so it syncs too.
2. **Your rate and hours were written to the shared file.** `hourlyRate` was in `settings`, and
   `settings` went to Drive; the time log went with it. *Fix:* `PRIVATE_SETTING_KEYS` (rate, theme,
   auto-sync, and this device's Drive file/folder/scope) never leave the device and are never taken
   from a remote copy. A new "Time log in the Drive file" switch keeps time entries out of the pushed
   payload and ignores remote ones when off.
3. **Two people syncing at once lost one of their edits.** Pull → merge → push had no check that the
   file was still what we pulled. *Fix:* the file's `modifiedTime` is re-read before the push; if it
   changed, the newer copy is pulled and merged first (up to three rounds). The sync toast reports it.
4. **No safety net.** No backups, no undo, a crash hid the data, a bad import replaced everything.
   *Fix:* rolling local backups (daily and before import-replace, reset, restore) with a Restore table
   in Settings; Undo on every delete (project, note, permit, time entry, team member); an error
   boundary with an export button; a one-time warning when the browser refuses to store; import and
   Drive files are shape-checked before use; persistence is debounced and flushed on tab hide.
5. **The allowed-emails box could not take a second line.** Every keystroke re-split and re-joined the
   text, eating the newline. *Fix:* local draft committed on blur, accepting newlines, commas or
   semicolons.
6. **Smaller bugs.** "Hours this month" compared a UTC month to local dates; the guide's `?q=` filter
   was ignored once on the page; the auto-sync watermark used a stale value; the sheet page-number
   input accepted empty/zero; `migrate(null)` would throw.
7. **No trace of who changed what in a shared file.** *Fix:* `updatedBy` stamped on every edit from the
   signed-in user, shown on the project record.
